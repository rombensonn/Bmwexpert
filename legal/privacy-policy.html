Политика обработки персональных данных

Важно: перед публикацией сайта владелец должен заменить placeholders в квадратных скобках на реальные сведения об операторе персональных данных.

1. Общие положения

Настоящая Политика определяет порядок обработки персональных данных пользователей сайта [Домен сайта], принадлежащего оператору: [Полное наименование оператора], ИНН [ИНН], ОГРН/ОГРНИП [ОГРН/ОГРНИП], юридический адрес: [Юридический адрес].

Контакты для обращений по вопросам персональных данных: [Email для обращений по персональным данным], [Телефон].

2. Какие данные обрабатываются

Оператор может обрабатывать имя, номер телефона, марку и модель автомобиля, выбранный тип услуги, удобное время визита, комментарий пользователя, технические данные формы заявки, страницу отправки, referrer, UTM-метки, IP-адрес и user-agent.

3. Цели обработки

Данные используются для обработки заявки, обратной связи с пользователем, записи в автосервис, уточнения стоимости и времени визита, ведения внутреннего учёта обращений и обеспечения безопасности сайта.

4. Правовые основания

Обработка выполняется на основании согласия пользователя, а также для принятия мер по запросу пользователя до заключения договора на оказание услуг.

5. Срок хранения

Персональные данные хранятся не дольше, чем требуется для целей обработки, если иной срок не установлен законом или договором. Рекомендуемый срок для заявок должен быть определён владельцем сайта отдельно.

6. Передача третьим лицам

Данные могут передаваться подрядчикам, которые помогают обслуживать сайт, хостинг, почту, телефонию или CRM, только в объёме, необходимом для обработки заявки. Реальные сервисы и условия передачи нужно заполнить владельцу сайта.

7. Права субъекта персональных данных

Пользователь вправе запросить сведения об обработке, уточнение, блокирование или удаление персональных данных, а также отозвать согласие, направив обращение на [Email для обращений по персональным данным].
